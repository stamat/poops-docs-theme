# Deeper

A section nested inside `Guide`, which makes this the third level of the sidebar tree. It
exists for that alone: two levels of nesting render through a different branch of
`navtree.html` than three do, so a preview site that stops at two audits markup no reader
ever gets.

Nothing here is about the theme's prose. The page under this one is a stub for the same
reason.
